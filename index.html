Projects I have done:

React Firebase LearnPlatform

I developed Lesson Flow, a learning platform built with React and Firebase. The goal was to create a simple way for users to build and manage courses. I implemented user authentication, course creation tools, real‑time Firestore data, media uploads via Firebase Storage, and a fully responsive UI. My work improved the project’s structure, performance, and overall user experience.

Responsive React Website - Figma to Multilingual Development

Developed a multi-page React website from Figma for a real client project. Implemented 3 languages with a language switcher, payment functionality, and fully responsive layouts for desktop, tablet, and mobile. Built reusable React components and translated the Figma designs into a polished, functional website with clean and maintainable code.

Responsive React Landing Page - Figma to React

I developed a fully responsive landing page using React, based on a custom design provided in Figma. The entire website was built from scratch by me, including layout structure, component logic, and styling. I ensured seamless adaptability across devices, with a mobile-first approach for optimal performance on smartphones and tablets.
